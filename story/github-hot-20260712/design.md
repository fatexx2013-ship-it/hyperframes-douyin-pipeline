# 科技新闻视频模板 — design.md

## 品牌色彩

| 用途 | 颜色 | 说明 |
|------|------|------|
| 背景 | `#ffffff` | 纯白 |
| 主文字 | `#111111` | 深黑 |
| 强调色 | `#2563eb` | 科技蓝 |
| 次强调 | `#10b981` | 生态绿 |
| 辅助灰 | `#6b7280` | 副文本 |
| 卡片底 | `#f9fafb` | 极浅灰 |
| 边框 | `#e5e7eb` | 淡灰线 |

## 字体

- 标题：`"SF Pro Display"`, weight 800-900
- 正文：`"PingFang SC"`, weight 500-600
- 数据：`"SF Mono"`, weight 400

## 卡片规范

- 圆角：16px
- 阴影：0 2px 8px rgba(0,0,0,0.06)
- 内边距：32px
- 边框：1px solid #e5e7eb

## 动效签名

- 入场 ease: `power3.out`
- 典型时长: 0.6s
- 停留时长: 2-4s

## 视频规范

- 画布: 1080x1920 (竖屏 9:16)
- 帧率: 30fps
- 风格: 干净白底 + 卡片式布局 + 动态数据展示

## 不做

- 不用深色背景
- 不用渐变
- 不在同一帧放超过两行大文字
- 装饰元素不超过 3 个
